# 📊 Amazon Sales Data Analysis Using SQL

This repository contains a collection of SQL queries designed to analyze sales, pricing, discounts, reviews, and product categories from an Amazon e-commerce dataset. The project showcases practical use cases of SQL for data analysis, driven by real-world business questions.

## 📌 Objectives

The primary aim of this project is to:

- Analyze product pricing, discounts, and sales patterns.
- Extract actionable insights from customer reviews.
- Understand trends in product categories.
- Build efficient and readable SQL queries for real-world use.


## ✅ SQL Queries Included

The repository includes SQL scripts that answer the following questions:

1. List all products with a discounted price below ₹500.
2. Find products with a discount percentage of 50% or more.
3. Retrieve all products where the name contains the word "Cable."
4. Display the difference between the average actual price and discounted price for each product.
5. Query reviews that mention "fast charging."
6. Identify products with a discount percentage between 20% and 40%.
7. Find products priced above ₹1,000 and rated 4 stars or higher.
8. Find products where the discounted price ends with a 9.
9. Display reviews that contain keywords like "worst," "waste," "poor," or "not good."
10. List all products in the "Accessories" category.
